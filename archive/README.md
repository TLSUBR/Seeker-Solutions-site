# ARCHIVED WEBSITE CONTENT

This directory contains the previous version of the Seeker Solutions website before migration to the new single-file architecture.

## Files included:
- `old-index.html` - Previous main HTML file
- `package.json` - Old npm configuration
- `DESIGN.md` - Old design system documentation
- `speed-insights.js` - Old speed insights setup

The new website is now served from the root `index.html` file.

## To restore the old website:
If needed, you can restore files from the `archive/` branch on GitHub.
